# Üçüncü Parti Açık Kaynak Lisansları

EvrakPlus Ders Dağıtım Multi Plus aşağıdaki açık kaynak kütüphane ve optimizasyon motorlarını kullanır:

| Bileşen | Lisans | Açıklama |
|---|---|---|
| Google OR-Tools | Apache-2.0 | CP-SAT optimizasyon motoru |
| Timefold Solver | Apache-2.0 | Kısıt tabanlı yerel arama ve kalite optimizasyonu |
| Choco Solver | BSD-4-Clause | Java tabanlı kısıt programlama motoru |
| MiniZinc | MPL-2.0 | Modelleme dili ve derleyici (Gecode: MIT, Chuffed: MIT) |
| SCIP / PySCIPOpt | Apache-2.0 / MIT | Tamsayılı matematiksel optimizasyon çözücüsü (SCIP 8+ Apache-2.0) |
| HiGHS / highspy | MIT | Yüksek performanslı MILP çözücüsü |
| Eclipse Temurin JRE (OpenJDK 21) | GPL-2.0 with Classpath Exception | Timefold ve Choco için paylaşımlı gömülü Java çalışma ortamı |
| Electron | MIT | Windows masaüstü uygulama çerçevesi |
| Tailwind CSS / Lucide / SheetJS | MIT / ISC / Apache-2.0 | Arayüz stilleri, ikonlar ve XLSX dışa aktarma |

Tam lisans metinleri derleme paketinde `resources/licenses/` dizininde yer alır.
